# Evening review

1. **Completed today**: emails he sent (Outlook Sent Items), meetings held (calendar, Granola notes), tasks marked
   done in `Setz/Log/tasks.md`.
2. **Outstanding**: this morning's top five that did not happen; tasks due today still open.
3. **Developments**: replies from partners, universities or investors; anything that changes a plan.
4. **Unanswered**: threads where he still owes a reply, oldest first.
5. **Coming up**: deadlines in the next three days; tomorrow's meetings and what each needs.
6. **Tomorrow's priorities**: propose five, in order, with one line each.

## Output
Six short sections in that order, readable on the phone. End with "Prepared for you": drafts waiting in Outlook
Drafts (he often writes at night and schedules sends for the morning).

Then:
- update `Setz/Log/tasks.md` (mark done, carry over, add new tasks found in today's mail and meetings),
- update `Setz/Log/followups.md`,
- add durable facts learned today to the right knowledge file with the date,
- save the review to `Setz/Log/briefings/YYYY-MM-DD-evening.md`.
Never send anything. Mark all drafts PREPARED.
