# Settleezy

**Settleezy helps students in Berlin, especially international students, save money and settle in.**

- **Membership app**, for students who are new to Berlin and those already here: save at restaurants, cafés, grocery stores, activities, events and more, plus guides, an expense and savings tracker, a document vault and emergency numbers.
- **Workshops**: building a portfolio, writing a CV, and more.
- **Buddy platform for universities**: A-to-Z support for new incoming students, including accommodation support.
